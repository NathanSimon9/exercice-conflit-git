# Exercice : provoquer et régler un conflit

Exercice en duo du cours Web 5 (Collège Montmorency).

Les consignes complètes sont dans le compendium :
https://tim-montmorency.com/compendium/582-511-web5/projets/recit-defilant/exercice-conflit.html

## En bref

1. Chacun crée **sa** branche, à son prénom, à partir de `main`.
2. Chacun modifie **la même ligne** de `index.html`, puis fait un *commit* et un *push*.
3. La première *pull request* passe. La deuxième bloque : c'est le conflit.
4. On le règle, à deux, puis on inverse les rôles.

Convention de *commits* : `Zone : ce qui a changé`, à l'impératif.
Ex. `Commun : change le titre de la page`.
